# A 股 Agent 纸面组合设计

## 目标

将 Agent 纸面组合实验从美股 ETF 示例切换为 A 股指数和 ETF 示例，使用 Tushare 日线数据，并在模拟器中体现 A 股常见的整数手、费用和涨跌停约束。

## 范围

- 默认标的为 `000300.SH`、`000905.SH`、`510300.SH`、`512100.SH`。
- 行情来源为 Tushare。支持现有的 `TUSHARE_TOKEN_2`、`TUSHARE_API_URL_2` 转发配置，并回退到 `TUSHARE_TOKEN`、`TUSHARE_API_URL`。
- 每个交易日使用最近一个交易日的收盘价生成决策输入。
- 模拟器按目标权重调整组合，股票和 ETF 按 100 股整数手成交。
- 卖出收取手续费，股票卖出收取印花税，买入和卖出都收取佣金。
- 对非现金标的使用涨跌停价格限制。没有提供前收盘价时不启用涨跌停判断。
- 继续只做多、保留最低现金比例，不连接券商，不发送真实订单。
- OpenRouter 继续作为默认模型提供商，智谱保留为回退选项。

## 不在范围内

- 真实账户、真实订单和券商连接。
- 分钟级行情和盘中决策。
- 复杂的停牌、集合竞价、北交所和科创板差异化规则。
- 自动提交代码或自动修改策略规则。

## 数据合同

价格输入继续使用：

```json
{
  "asOf": "2026-09-01",
  "prices": {
    "000300.SH": 3900.0,
    "000905.SH": 5200.0,
    "510300.SH": 4.1,
    "512100.SH": 1.2
  }
}
```

如数据源提供前收盘价，额外使用内部字段 `previous_closes` 判断涨跌停。该字段不会破坏已有价格输入消费者。

## 验收标准

- 本地价格命令默认请求 A 股标的，不再请求 `SPY`、`QQQ`、`TLT`、`GLD`。
- 没有 Tushare 配置时，命令给出清晰错误，不静默切换到美股数据。
- 模拟器不得产生非 100 股整数手的非现金交易。
- 卖出股票会计入印花税，ETF 不收印花税。
- 涨停时禁止买入，跌停时禁止卖出。
- GitHub Actions 使用新的 Tushare 和 OpenRouter 环境变量。
- 原有纸面组合 schema、静态 Dashboard 和离线模型响应流程继续可用。
